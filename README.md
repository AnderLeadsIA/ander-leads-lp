# AnderLeads.IA — Planos e valores

Landing page estática em HTML, CSS e JavaScript. Não precisa de instalação nem build.

## Estrutura

```text
index.html
assets/
  css/style.css
  js/app.js
  js/config.js
  img/
vercel.json
.gitignore
README.md
```

## Ver localmente

Abra `index.html` no navegador ou execute `python -m http.server 8765` nesta pasta e acesse http://localhost:8765.

## GitHub e Vercel

1. Envie o conteúdo desta pasta para um repositório no GitHub, com `index.html` na raiz.
2. Na Vercel, importe esse repositório.
3. Use Framework Preset: **Other** e Root Directory: **./**.
4. Não configure comando de instalação nem de build. O `vercel.json` define a saída na raiz.
5. Clique em Deploy.

## Editar

- Textos, preços e planos: `index.html`.
- Estilos: `assets/css/style.css`.
- WhatsApp e Instagram: `assets/js/config.js`.
- Botões e eventos: `assets/js/app.js`.
- Imagens: `assets/img/`.
